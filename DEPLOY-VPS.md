# Перенос сайта на VPS (Cityhost)

Всё ставится одним скриптом. Твоя задача — скопировать команды по порядку.

---

## Шаг 0. Что нужно под рукой

- **IP сервера и пароль root** — в панели Cityhost, раздел VPS.
- **Операционка сервера** — должна быть **Ubuntu 22.04 или 24.04**.
  Если стоит другая (CentOS, Debian, Windows) — в панели Cityhost нажми
  «Переустановить ОС» и выбери Ubuntu 24.04.
- **Строка подключения к базе** (DATABASE_URL) — она уже есть в твоём
  локальном файле `.env`, скопируй её оттуда целиком.

---

## Шаг 1. Подключиться к серверу

Открой PowerShell на своём компьютере и выполни (вместо `1.2.3.4` — твой IP):

```
ssh root@1.2.3.4
```

Первый раз спросит «Are you sure you want to continue connecting?» — напиши `yes`.
Потом введи пароль root (при вводе пароль **не отображается**, это нормально).

---

## Шаг 2. Скачать проект

Копируй целиком и вставляй в терминал сервера:

```
apt update && apt install -y git && mkdir -p /var/www && git clone https://github.com/venzyyyk/rezervmenu.git /var/www/dryleaf
```

---

## Шаг 3. Запустить установку

```
bash /var/www/dryleaf/deploy/setup.sh
```

Скрипт задаст 4 вопроса:

1. **Домен** — если домена ещё нет, просто нажми Enter (сайт будет работать по IP).
2. **DATABASE_URL** — вставь строку из своего `.env`.
3. **Email для админки** — Enter, если устраивает `admin@dryleaf.local`.
4. **Пароль для админки** — придумай нормальный, не `dryleaf123`.

Дальше он сам поставит Node, PM2, nginx, firewall, соберёт сайт, выпустит SSL
и запустит всё. Занимает 5–10 минут, в конце покажет адрес сайта.

---

## Шаг 4. Проверить

- Сайт: `http://IP-сервера` (или твой домен)
- Админка: `http://IP-сервера/admin/login`

---

## Если есть домен

1. У регистратора домена в DNS создай две A-записи на IP сервера:
   - `@` → `1.2.3.4`
   - `www` → `1.2.3.4`
2. Подожди 10–30 минут, пока обновится DNS.
3. На сервере выполни (вместо `dryleaf.com.ua` — свой домен):

```
certbot --nginx -d dryleaf.com.ua -d www.dryleaf.com.ua
```

Сертификат бесплатный и продлевается сам.

⚠️ После смены адреса обнови в `/var/www/dryleaf/.env` строки `NEXTAUTH_URL`
и `NEXT_PUBLIC_APP_URL` на новый домен, потом `pm2 restart dryleaf`.
И перепечатай QR-коды столов — они содержат полный адрес.

---

## Дальнейшая работа

**Обновить сайт после моих правок** (ты делаешь `git push` у себя, потом на сервере):

```
bash /var/www/dryleaf/deploy/update.sh
```

**Полезные команды:**

| Что | Команда |
|---|---|
| Посмотреть логи | `pm2 logs dryleaf` |
| Перезапустить | `pm2 restart dryleaf` |
| Статус | `pm2 status` |
| Перезапустить nginx | `systemctl reload nginx` |

Сайт запускается сам после перезагрузки сервера — PM2 это делает.

---

## Что можно вернуть после переезда

На Render было отключено сжатие картинок из-за нехватки памяти (512MB).
На VPS памяти больше, так что можно включить обратно — в `next.config.mjs`
убрать строку `unoptimized: true`, потом `git push` и `update.sh`.
Меню станет грузиться быстрее. Скажи мне — сделаю.

---

## Больше не нужны

После переезда можно выключить:

- сервис на Render (Settings → Delete Service);
- пингер на cron-job.org (он больше не нужен — VPS не засыпает).

База Neon остаётся как есть, её не трогаем.
